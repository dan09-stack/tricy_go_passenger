# TricyGo Frontend

This directory contains the frontend applications for the TricyGo platform.

## Components
1. **Passenger App**: Flutter-based mobile application for riders.
2. **Driver App**: Flutter-based mobile application for tricycle drivers.
3. **Admin Dashboard**: Web-based interface for platform management.

## Technology Stack
- **Framework**: Flutter (Mobile)
- **State Management**: Riverpod
- **Navigation**: GoRouter
- **Maps**: Google Maps Platform / Mapbox
- **Web**: React (for Admin Dashboard)
