# TricyGo Backend

This directory contains the backend services for the TricyGo platform.

## Technology Stack
- **Runtime**: Node.js
- **Framework**: NestJS
- **Language**: TypeScript
- **Database**: PostgreSQL with PostGIS
- **Caching**: Redis
- **Real-time**: Socket.IO

## Features
- User Authentication (OTP via phone)
- Ride Booking Logic
- Real-time Driver Tracking
- Fare Calculation
- Payment Integration
- Administrative API
